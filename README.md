# Personal CV Website

## Short Description

A responsive personal CV and portfolio website that presents my profile, education, skills, projects, achievements, work experience, and contact links. It features a blue theme, interactive navigation, animated sections, and a print-friendly layout.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- SVG
