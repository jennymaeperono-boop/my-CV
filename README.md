# Personal CV Website

A responsive personal CV and portfolio template built with plain HTML, CSS, and JavaScript. No build tools or package installation are required.

## Run locally

Open `index.html` in a web browser. For the best experience, use a local development server such as the VS Code Live Server extension.

## Customize your CV

Edit `index.html` to replace the sample name, portrait, introduction, contact details, education, skills, projects, achievements, experience, and social profile links with your own information. Update the page title and description in the document `<head>` as well.

Replace the sample certificate illustrations in `assets/` with photos of your actual certificates or achievements. Update the corresponding image paths in `index.html`. The profile portrait and project previews use externally hosted images; replace those image URLs with your own if desired.

GitHub, LinkedIn, and social links are grouped in the contact section. Replace the `yourusername` URLs with your profile links.

## Included interactions

- Responsive navigation with an accessible mobile menu
- Smooth scrolling and scroll-triggered section reveals
- Hover effects on buttons, skills, and project cards
- A print-friendly layout; use **Download CV** to print or save the page as a PDF
- Reduced-motion support for visitors who prefer less animation
